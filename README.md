# Ticket digital · Sistema de Turnos DEVA

Página estática que muestra el turno en el celular a partir del código QR que entrega Recepción.

- No guarda datos, no tiene formularios ni cookies y no se conecta a ningún servidor.
- Los datos del turno viajan en el enlace después de `#` (esa parte no se envía por internet).
- El código de verificación lo firma el sistema interno; esta página solo lo muestra.
